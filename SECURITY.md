# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

## Reporting a vulnerability

**Do not open public issues or PRs for security vulnerabilities.**

Use GitHub's private vulnerability reporting instead: **Security → Report a vulnerability** on this repository (`https://github.com/LucianoDPerez/sdlc-skills/security/advisories/new`).

Please include:

- The affected file and line (e.g. `skills/security/references/owasp-checklist.md`)
- Why the guidance is insufficient or wrong, with a concrete scenario
- Suggested correction

You should receive a response within 7 days. Credits in the advisory are optional — tell us your preference.

## Scope

This repository contains instruction files (`SKILL.md`, templates, references). Vulnerabilities here are **unsafe guidance** — instructions that would lead an agent to produce insecure systems (e.g., a checklist that marks an unsafe pattern as passing). Vulnerabilities in downstream products built with these skills are the responsibility of those products.
