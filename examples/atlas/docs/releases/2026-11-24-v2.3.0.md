## 6. Runbook (embedded — short)

- Job stuck in `running` >2h → worker `ps`, restart job pool; stuck jobs marked failed with problem code `export.worker_stalled` (retryable).
- Artifact expired before download → tenant re-requests (idempotent UX: same key, new job).
- Flag off → `atlas flags set tenant_export off`.

## 7. Rollback trigger criteria

- API p95 >200ms for 15 min → flag off.
- export_authz_denied spike (>10/hour) → flag off, investigate IDOR before resume.
- export job success <90% over 24h → stop phase advance, hold at current scope.
